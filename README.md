# vibe-coding-checkpoint-4# Todo App

A small, single-page Todo application using plain HTML/CSS/JavaScript.  
Features: add, edit, mark complete, delete, filter, clear completed, and persistent storage via localStorage.

## Live demo
(After you push and enable GitHub Pages, the app will be available at https://<your-username>.github.io/<repo-name>/)

## Files
- index.html — main HTML
- styles.css — styling
- app.js — application logic (vanilla JS)
- README.md — this file

## How to run locally
1. Save the files in a folder (e.g., todo-app/).
2. Open index.html in your browser (double-click or File → Open).
3. Or run a quick static server (optional, recommended if you use modules later):

```bash
# from the project folder
python -m http.server 8000
# then open http://localhost:8000 in your browser
